# 🎓 College Event Management System

A full-stack web application to manage college events.  
Users can **add, view, update, and delete events** through a simple and modern user interface.

---

## 🚀 Features

- ➕ Add new events  
- 📋 View all events  
- ✏️ Edit existing events  
- 🗑️ Delete events  
- 🎨 Modern UI with animations and icons  
- ⚡ Real-time updates using React  

---

## 🛠️ Tech Stack

### Frontend:
- React.js  
- CSS (Custom styling + animations)  
- React Icons  

### Backend:
- Node.js  
- Express.js  

### Database:
- MongoDB (with MongoDB Compass)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
git clone https://github.com/tejuprk350/college-event-management.git
cd college-event-management
---

### 2️⃣ Setup Backend
cd backend
npm install
npx nodemon server.js

---

### 3️⃣ Setup Frontend

(Open a new terminal)
cd frontend
npm install
npm start

---

## 🌐 Running the Project

- Backend runs on:  
  http://localhost:5000  

- Frontend runs on:  
  http://localhost:3000  

---

## 🔄 How It Works

- React frontend sends requests using **fetch API**  
- Backend (Express) handles API requests  
- MongoDB stores event data  
- CRUD operations are performed:
  - Create → Add Event  
  - Read → View Events  
  - Update → Edit Event  
  - Delete → Remove Event
